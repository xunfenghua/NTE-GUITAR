# Changelog

Notable user-facing changes are recorded here. Exact release assets and checksums are attached to [GitHub Releases](https://github.com/xunfenghua/-/releases).

## 3.4.0 — Lite public source distribution

- Publishes the Windows desktop client source, optional announcement/recommended-score service source, and implemented algorithm modules.
- Includes MIDI and Guitar Pro import, score editing, 36-key/piano/guitar compilation, local library, semi-auto overlay, and optional local audio-to-score code.
- Adds reproducible Lite packaging and a verified, opt-in ViGEmBus download script.
- Excludes workspace build caches, large media, local logs, bundled song examples, Python runtime, FFmpeg, model weights, and driver installer binaries.
- Adds Chinese and English README files plus architecture, algorithm, model setup, and third-party license documentation.

This entry describes the current project-file version and the public Lite package contents. It is not a claim that every optional model or driver has been installed and tested on every Windows environment.
