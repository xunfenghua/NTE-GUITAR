# V3.0 验收测试清单（首轮）

## Game Piano（软件验收）
- [x] 独立导航页和编译入口；旧 36 键钢琴仍使用原 Keyboard36 模式。
- [x] 七键/十二键 profile 独立保存；未校准扫描码不会从旧模式继承，未完成校准时阻止播放。
- [x] 七键只映射当前调式中的精确音级，校准捕获限制为 A–Z 字母键，不产生 Shift/Ctrl。
- [x] 十二键优先直接音高键，Shift/Ctrl 仅使用单独验证过的方向、步长和扫描码。
- [x] MIDI 预览显示可演奏/跳过数量、谱面时间轴和带时间/轨道/音高的诊断；问题可定位播放头。
- [x] 变速、鼓声道过滤、移调、跳过确认和同键重叠处理已由自动化用例覆盖。
- [x] 播放使用独立 Piano 编译结果、绑定游戏前台保护，并在暂停/停止/失焦时释放已按下键。
- [ ] 实机校准每个音区键位、十二键修饰键、实际音高和复音上限；此项必须在目标游戏中完成，不能由软件测试代替。

软件自动验收（2026-10-19）：Release 构建 0 警告/0 错误；自动化测试 527 通过、0 失败。实机校准仍待用户在游戏内完成。

## GuitarChartCompiler
- [ ] 空 MIDI 不崩溃，生成空谱面。
- [ ] E4 可生成物理 1 弦 / 游戏键 6 的候选；E2 可生成物理 6 弦 / 游戏键 1 的候选。
- [ ] fret=0 -> P0/Slot 1；1..6 -> P1；7..12 -> P2；13..18 -> P3；19..24 -> P4。
- [ ] 并发音符优先寻找可共用的品位；找不到时保留所有目标音符并标记 NO_COMMON_FRET。
- [ ] 不会因准备时间不足静默删除事件。
- [ ] 首个位置只参与开局预定位，不生成正式位置切换事件。
- [ ] 每个音符都可追溯到源轨道、源音高和时间戳。

## 模式隔离
- [ ] 练习模式按错显示反馈，但时间轴继续走。
- [ ] 普通音游自动切换位置。
- [ ] 地狱音游由玩家确认位置切换。

## 悬浮窗 / WebView2
- [ ] 暗/亮主题跟随主应用。
- [ ] DPI 100/125/150/200% 下布局不重叠。
- [ ] 1080p/2K/4K 下可用。
- [ ] 隐藏热键不影响游戏键输入。
- [ ] 鼠标穿透与交互模式在目标 Windows 版本实测。
- [ ] 页面关闭、游戏失焦、异常退出沿用全量放键保护。
