# 吉他模拟手柄与键鼠模式核心算法

**源码基准：** NET-GUITAR 工作区，2026-10-23  
**范围：** 虚拟 Xbox 手柄输出的全部吉他模式，以及键盘/鼠标相关的全部主播放模式（36 键、吉他三模式、四键鼓点、独立游戏钢琴）。  
**阅读方式：** 本文汇总决策链和输入执行差异。和弦识别、品格全局选弦、混合模式动态规划及各乐器映射的逐项细节见文末关联文档。

## 1. 先区分两种“模式”

`AppConfig.PlayMode` 决定**音乐如何转成吉他动作**：

| PlayMode | 弹奏模式 | 主要算法 | 主要输出动作 |
|---:|---|---|---|
| 1 | 品格独奏 | 音符净化、全曲八度选择、弦/品候选、全局路径规划 | 翻页、选槽、指定琴弦起音 |
| 2 | 和弦伴奏 | 和弦推断、攻击过滤/伴奏编排、和弦页槽及弦动作编译 | 翻页、选和弦、块拨/扫弦/分解拨弦 |
| 3 | 完整混合演奏 | 逐攻击帧生成品格与和弦候选、全曲规划模式/页面/槽位 | 上述动作，加模式切换 |

`AppConfig.UseVirtualGamepad` 决定**动作由什么设备表示并发出**：

| 输出设置 | 控件/协议 | 控制映射摘要 |
|---|---|---|
| 关闭：键盘/鼠标 | Win32 `SendInput` | Z 切换弹奏模式；R/T 翻页；轮盘坐标点击选槽；琴弦键和扫弦鼠标键发声 |
| 开启：模拟手柄 | ViGEm 虚拟 Xbox 360 手柄 | 右扳机切模式；LB/RB 翻页；左摇杆方向脉冲选槽；琴弦映射到方向键/面键；右摇杆纵向脉冲扫弦 |

手柄输出只用于主吉他 PlayMode 1–3。主播放入口另外还包含 PlayMode 0（36 键键盘）和 PlayMode 4（四键鼓点），它们始终由键盘扫描码输出；游戏钢琴则是独立校准会话，也使用键盘扫描码与可选修饰键。它们没有被虚拟手柄路由。

“模拟手柄”不是另一套音乐转谱算法。三种 PlayMode 先编译出 `GuitarAction`；启用手柄后，时间参数会按手柄采样特性配置，并在调度前额外规划方向键琴弦动作。键鼠路径沿用相同的音乐决策，只在动作编译时使用相应的键鼠等待值和物理控件。

## 2. 总体数据流

```text
MIDI 原始音符
  → 速度/时值缩放、吉他模式公共过滤
  → PlayMode 1 / 2 / 3 音乐算法
  → GuitarAction（目标页、槽、琴弦、按下/抬起、时间/截止时间）
  → 若启用模拟手柄：GamepadActionPlanner.StaggerDpad
  → GuitarScheduler：前台窗口与会话状态检查、按绝对时间调度
  → 键鼠 SendInput 或 VirtualGamepadController / ViGEm
```

时间以微秒为主。编译器规划目标起音时间及控制动作；调度器等待目标时间、检查动作所需的页/槽状态、处理暂停/停止/失焦和失败释放。因为硬件/游戏输入有最短保持和控制间隔，输出事件不保证与 MIDI 起音逐微秒一致；可行性检查或调度会延迟、跳过或释放动作。

## 3. 三种弹奏模式的算法核心

### 3.1 PlayMode 1：品格独奏

实现主链：`FretConverter.Convert` → `GuitarCompiler.CompileFretEvents`。

1. **音符清理。** 排除鼓声道、排序；默认按 15 ms 起音并发组做单音化，同组保留最高音（同音高取力度较强者），快速重复音不与延音尾部合并。
2. **全曲统一八度。** 对候选八度偏移评分，奖励进入标准吉他 MIDI 40–88 音域的音符，惩罚超范围及偏高把位，并扣除整体移调幅度。整曲用同一个偏移，保持旋律轮廓；不能奏的音保留跳过路径，不逐音夹音。
3. **弦/品候选。** 标准调弦 1 弦到 6 弦为 `[64,59,55,50,45,40]`；对每音枚举有效弦/品候选，并有 Skip 兜底。品位映射到 P1–P4 的六槽；空弦映射 P5/S1。
4. **全局路径优化。** 用前后音位置代价规划弦、品、页面、槽位，而不是每个音独立选最近位置；代价考虑移动、换弦、页面/槽变化、快速重复和可达时间。`UseVirtualGamepad` 会提高轮盘 settle 时间，并采用更适合手柄节奏的快速动作窗口/惩罚参数。
5. **编译与校验。** 将事件变成翻页、轮盘选槽、琴弦 Down/Up；计算硬件时间约束并给出时间线可达性报告。手柄路径琴弦最短按住时间至少 50 ms、同一弦重触发需留至少 35 ms。

### 3.2 PlayMode 2：和弦伴奏

实现主链：`ChordAnalyzerV2.AnalyzeDetailed` → `AccompanimentEventFilter.Prepare`（或 `ArrangedAccompanimentCompiler.Compile`）→ `GuitarCompiler.CompileChordDetailedEvents`。

1. **半音移调与和弦证据。** 分析器搜索半音移调，使音符更贴合游戏内置 24 个和弦；在起音聚类和约 320 ms 和声窗口内，依据音高类别、重叠/力度/音区/时值等累计证据。
2. **和弦状态稳定。** 对内置和弦候选评分，结合倾向模式（Strict、Loose、BassRoot）及最短稳定期、迟滞抑制槽位抖动；未知和弦不会生成实际和弦变化动作。
3. **伴奏攻击选择。** 基于和弦事件与原始音符过滤主旋律起音；依据配置的 voicing、play style、AutoStrum 选择可弹奏弦及块拨、扫弦或分解音型。启用编排伴奏时按小节、节拍、密度、力度、低音/鼓点选择律动，并为换和弦控制留提前量。
4. **控制动作编译。** 和弦页槽变化变为翻页/选槽，发声变为琴弦按键或扫弦点击；手柄模式使用对应的硬件时间参数。

分析和弦名称/和弦槽位与“实际逐根弦音”不同：游戏和弦是固定和弦预设，发声动作需按预设安全弦及 voicing 再编译。和弦伴奏可达性报告不会做品格独奏那样的弦品可达性验证。

### 3.3 PlayMode 3：完整混合演奏

实现主链：`HybridGuitarCompiler.CompileFullPerformance`。

1. **输入预处理。** 基于原始音符做吉他复音减量和速度优化；并运行和弦/移调分析，构造对齐后的试听音符。
2. **按攻击帧构造候选。** 每个同时/近同时攻击时刻，评估品格候选与和弦候选，包括是否保留成和弦、转为单音/部分音、跳过或切换演奏模式。
3. **全局动态规划。** 在整曲或规划窗口上比较候选路径的音符覆盖、移页/移槽、弦位移动、切换模式和控制时间成本，避免局部看似合理但连续不可达的动作。初始约定是品格模式 P1；需要时通过 Z（或手柄右扳机）切入和弦模式。
4. **时间和硬件适配。** 编译阶段考虑琴弦最短按住、释放间隔、翻页间隔、选槽 settle 及模式转换下限；手柄参数不同于键鼠参数。最后输出统一 `GuitarAction`。

混合模式是单一的全局决策路径，不是简单地把 Mode 1 和 Mode 2 两份动作列表叠加；局部选择需与后续模式/页面控制动作兼容。

## 4. 模拟手柄专属输入算法

### 4.1 虚拟 Xbox 控件映射

`VirtualGamepadController` 通过 ViGEm 创建 Xbox 360 虚拟控制器（不会自行安装驱动）。

| 吉他动作 | 虚拟 Xbox 输入 | 行为 |
|---|---|---|
| 琴弦 1–4 | D-pad 四方向 | D-pad 是一个方向帽，方向需逐个序列化，不能像四个独立按钮同时保持 |
| 琴弦 1–4 实际方向 | 1=下、2=左、3=右、4=上 | 来自 `ResolveStringButton` |
| 琴弦 5、6 | Xbox 面键：5=A、6=X | 可与 D-pad 琴弦分属不同输入资源 |
| 槽位 1–6 | 左摇杆 6 个定向向量 | 选槽时发送方向报告，约 50 ms 后自动回中 |
| 上/下翻页 | LB / RB | 按住/释放成脉冲；翻页先清除左摇杆方向与琴弦状态 |
| 切换品格/和弦 | 右扳机 | 按下/释放成脉冲；切模式前先清琴弦和摇杆状态 |
| 扫弦 | 右摇杆 Y 正/负方向 | 向上/向下脉冲，强制至少 50 ms，最长 80 ms |

运行时将按钮/摇杆报告显式提交；不会依赖系统按键焦点来生成虚拟手柄输入。连接失败保存在 `GamepadError`，开始阶段会检查连接并反馈失败。

### 4.2 手柄时间参数和方向键串行化

内置最低时序在 `GamepadInputTiming`：琴弦按住 50 ms，D-pad 回中 35 ms，同弦重触发释放间隔 35 ms，翻页按住 50 ms、释放间隔 35 ms，轮盘选槽后留至少 16 ms 起音前导。相关用户配置只会在这些硬下限之上增大约束。

`GamepadActionPlanner.StaggerDpad` 在模式专属编译后运行：

1. 按时间及动作优先级排序，先把每个琴弦 Down 与其 Up 配对，重复音按起音次序配对。
2. 把翻页、切模式、轮盘选槽视为控制屏障；在屏障之间独立规划 D-pad 琴弦。
3. D-pad 多弦攻击按时间排序；同一时刻按琴弦顺序铺开，两个方向之间至少间隔 50 ms 按住 + 35 ms 回中；同一方向重复至少间隔 50 ms + 35 ms。
4. 为满足下一控制屏障，可在攻击前借最多 25 ms；不能提前越过上个控制动作的等待时间。Up 被限制在下一方向攻击或控制动作前的安全点。
5. 只有整个方向键段可塞入控制屏障前，才提交重排；无法安排的段保持原样并记录警告，由控制器串行执行，因此高密度和弦可能让控制动作延迟。

弦 5/6 的面键起音不经 D-pad 逐方向铺开，保留其原定时间。此策略是因为 D-pad 只有一个方向状态；它不能把四个方向报告视为四根可并行保持的琴弦。

## 5. 键盘/鼠标输出算法

键鼠与手柄共用三种音乐模式及 `GuitarAction` 语义，但设备执行映射不同：

| 动作 | 键盘/鼠标行为 | 与模拟手柄的差异 |
|---|---|---|
| 琴弦 Down/Up | 按校准/默认扫描码按下、抬起；同一弦重拨需先释放 | 不需要 D-pad 方向串行化，琴弦键可由多个独立按键表达 |
| 翻页 | R/T 键脉冲（实际扫描码来自 WheelPreset） | LB/RB；通常手柄脉冲有 50 ms 最低保持及 35 ms 间隔 |
| 轮盘选槽 | 校准鼠标坐标点击槽位 | 左摇杆方向报告，定时自动回中 |
| 切换模式 | Z 键 | 右扳机 |
| 扫弦 | 校准鼠标左/右键点击 | 右摇杆 Y 轴正/负值 |

键鼠编译侧使用配置的页面键保持、点击/最短按键保持、释放间隔和鼠标 settle 时间下限；调度器逐动作检查所需页/槽状态和截止时间。失焦自动停止启用时，目标游戏不在前台会停止发送；暂停/停止会释放已按下琴弦键。点击位置来自轮盘校准配置，而非算法按屏幕分辨率猜测。

## 6. 两类输出实际共享和分叉的位置

| 阶段 | 共用？ | 说明 |
|---|---|---|
| MIDI 时间缩放、PlayMode 选择 | 是 | 相同音符/速度及模式设置进入相同音乐算法 |
| 品格/和弦/混合决策 | 是 | 算法输出抽象 `GuitarAction`，但选弦及模式规划会读取 `UseVirtualGamepad` 的时间约束 |
| 动作时间参数 | 否 | 手柄有 50 ms 琴弦/翻页最短采样要求、D-pad 中立和较短选槽前导；键鼠使用各自可配的按键和点击时间 |
| D-pad 动作后处理 | 仅手柄 | `StaggerDpad` 对 1–4 弦拆分并检查控制屏障 |
| 物理输入执行 | 否 | 键鼠发送扫描码/鼠标事件；手柄提交 ViGEm Xbox 报告 |
| 暂停、停止和异常清理 | 目标相同、实现不同 | 两侧都释放输入；手柄 ResetAll / 释放控制器状态，键鼠释放相关物理键 |

因此切换输出设备可能改变全局候选成本与可达性：不只是编译后的最后一步替换按键。尤其手柄 D-pad 的物理限制会让快速多音和弦被展开/延迟；键鼠独立弦键没有此项约束。

## 7. 键盘/鼠标的其它主播放模式

这些模式不走虚拟手柄，但属于键鼠输出算法范围。它们与吉他共用 MIDI 读入、键盘发送和播放生命周期的一部分，转换目标不同。

### 7.1 PlayMode 0：36 键键盘

`MidiConverter` 将 MIDI 音高映射到 E3–D#6（MIDI 52–87）的 36 个半音索引。流程按用户选择过滤轨道、鼓声道和零力度事件，应用用户移调；越界音符可按“八度折叠”将乐句整体移入音域，或直接舍弃。若为全曲识别，会先生成主旋律标记；折叠后伴奏音与当前主旋律相距小于 4 半音时会抑制碰撞。随后按起点去重同一音高，转换成 `GameNoteEvent`，由 `ActionCompiler` 依据 36 键预设扫描码、时长下限、重触发间隔和延音选项生成按下/抬起批次。

### 7.2 PlayMode 4：四键鼓点

`DrumMidiConverter` 先将起音按默认 20 ms 聚类，并根据小节、拍号和力度统计音符。若某小节有标准鼓声道（MIDI 的第 10 声道，零基 Channel 9），按 GM 音高表归类为底鼓、军鼓、轻镲、重镲；没有鼓轨的小节从旋律起音生成节奏：强拍/反拍、八分反拍、旋律音高走向、力度重音、每四小节末尾 fill、重复鼓种抑制和重 crash 冷却共同决定鼓种。输出按优先级筛到配置的同时按键上限（默认 2），同鼓种至少留 55 ms 冷却，按键至少保持 25 ms；默认扫描码为 D/F/J/K，另有 A/S/;/’ 预设。

### 7.3 独立游戏钢琴会话

游戏钢琴不使用主播放 PlayMode 编号，也不进入 `GuitarScheduler`。`PianoMidiCompiler` 校验已校准键位布局，再进行鼓声道过滤、全局移调选择和按乐句八度折叠，支持十二键半音布局与七键调式布局。音符匹配校准扫描码及可选 Shift/Ctrl 修饰键；编译阶段按 15 ms 起音簇处理和弦、修饰键冲突、物理键重叠与布局复音上限，并生成修饰键前导/脉冲和琴键按下抬起动作。十二键布局的修饰键冲突和七键布局非调式音会被自动协调/映射并在结果中报告；无效布局或缺失绑定会阻止开始。

主播放模式总表：

| 模式 | 输入算法 | 输出调度 |
|---|---|---|
| 0：36 键键盘 | 音域过滤/乐句八度折叠 → 36 音索引 → 用户预设 | `InputScheduler` / 键盘扫描码 |
| 1：吉他品格 | 单音净化 → 统一八度 → 弦品全局路径 | `GuitarScheduler` / 键鼠或手柄 |
| 2：吉他和弦 | 和弦证据 → 伴奏攻击/律动 → 游戏和弦编译 | `GuitarScheduler` / 键鼠或手柄 |
| 3：吉他混合 | 品格/和弦候选 → 全局模式路径 | `GuitarScheduler` / 键鼠或手柄 |
| 4：四键鼓点 | 鼓轨语义或旋律生成节奏 → 鼓种节流 | `InputScheduler` / 键盘扫描码 |
| 游戏钢琴 | 校准布局映射 → 冲突/复音处理 | `PianoSessionService` / 独立 Piano 调度 |
